## Deviations
- T2: added `Index` (prefix sums over typed rows) so pair building and the day check are fast; `typed_pairs` takes an optional index and `recent_mix` takes an `Index`, not the row list, which differs from the signatures in design.md.
- T4: added `rolling_steps()` so the no-leakage property can be tested directly; `rolling_errors()` summarises it.
- T5: `Forecaster.fit()` now derives the single ratio and the pair count from the typed pairs instead of calling `forecast_calibrate.tokens_per_percent()`; the same filters apply and a test checks the two agree.
- T5: the cold fit over the timing data rose from 1.9 to 2.33 seconds on this machine (limit 3 seconds), so the fallback of building typed rows only after the oldest reading was not needed.
- T7: only macOS was run. Windows and Linux runs remain open (see `verification.md`).
