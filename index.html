Data sources & accuracy

What these numbers mean

Totals sum recorded fresh input, cached input, cache writes, and output. Reasoning is a subset of output and is never added twice.

Codex joins log segments by thread and counts each response ID once. Legacy logs without response records use cumulative token_count deltas. Codex subagents join their root conversation when included. Claude Code deduplicates response usage across content blocks. Cost-state is a fallback when response usage is absent.

Context shows input plus output from the latest recorded response. Codex capacity comes from its log. Claude capacity, compaction thresholds, and system/tool/memory/skill token categories are unavailable unless explicitly recorded.

Time filters use usage-event timestamps in your browser’s local timezone. Undated cost-state totals appear only in “All retained logs”. Logs can be incomplete. Older saved captures may contain overlapping Codex log segments; a warning identifies these captures. “Recent” means a log changed within five minutes, not that a model is generating.

Reported cost comes from Claude’s cost-state, when present. It is not a subscription bill. No inferred prices or currency estimates.

Consumer ChatGPT and Claude browser chats are outside this local collector. Source logs are read only; no settings or proxy configuration are changed.
